# JNU 공지 한눈에

제주대학교 공지사항을 모아 마감일·등록금 일정·혜택 뉴스·제주 날씨와 함께 보여주는 학생용 **비공식** 웹사이트입니다.

사이트: https://a01099226860-tech.github.io/jnu-notice/

## 화면

| 보기 | 내용 |
|---|---|
| 공지 피드 | 왼쪽 **필터 사이드바**(검색·정렬·카테고리·마감·기타), 오른쪽 위 **이번 주 마감**, 그 아래 **3열 카드**. 카드를 누르면 **상세 모달** |
| 📅 등록금 캘린더 | 납부기간 월별 캘린더, 진행 중·곧 시작 일정 알림, `.ics` 로 내 캘린더에 알림 추가 |
| 📰 혜택 뉴스 | 대학생·청년 혜택(장학금·지원금·할인·모집) 기사, 제주 태그 |
| 헤더 날씨 알리미 | 제주 아라캠퍼스 현재 날씨·3일 예보, 우산/강풍/일교차 알림 |

공지 피드 규칙
- 들어오면 전체 피드가 보이고, 필터는 고를 때만 적용됩니다.
- 정렬: **마감임박순(기본)** / 최신 게시순.
- 마감이 지난 공지는 숨기고, **D-3 이하는 빨간 배지**.
- 결과 0건이면 "조건에 맞는 공지가 없어요. 필터를 바꿔보세요".
- 모바일(860px 이하)은 사이드바가 위로 올라가고 카드가 1열.

## 구조

```
scraper/crawl.py              수집기 (공지 + 혜택 뉴스 + 날씨)
scripts/update.py             PC 수동 업데이트 (수집 → 변경 시 커밋·push)
update.bat                    위 스크립트를 더블클릭으로 실행
docs/                         GitHub Pages 로 배포되는 정적 사이트
  index.html, style.css, app.js
  data/notices.json · news.json · weather.json
.github/workflows/crawl.yml   수집 작업 (30분마다 자동 + 수동 실행)
```

## 업데이트

**자동: 30분마다**

GitHub Actions 가 매시 7분·37분에 공지·날씨를 수집하고(뉴스는 6시간마다), 바뀐 내용이 있으면 커밋합니다. 사이트는 새로고침할 때마다 최신 데이터 파일을 받으므로, 방문자는 새로고침하면 최대 30분 전 데이터를 보게 됩니다. (GitHub 사정으로 실행이 몇 분~수십 분 늦어질 때가 있습니다.)

**바로 갱신하고 싶을 때: 수동 실행**

저장소 → **Actions** 탭 → 왼쪽 **공지 수집** → **Run workflow**. 1분 안팎이면 끝나고 1~2분 뒤 사이트에 반영됩니다. 휴대폰 GitHub 앱에서도 됩니다.

**예비: 이 PC 에서 실행**

제주대 서버가 GitHub 서버(해외 IP) 접속을 막을 때가 있습니다. 그러면 Actions 실행 결과에 빨간 실패와 함께 "제주대 서버가 GitHub Actions 접속을 거부했습니다"가 표시됩니다. 이때는 한국 IP 인 PC 에서 프로젝트 폴더의 **`update.bat` 를 더블클릭**하세요. 수집하고 바뀐 내용만 GitHub 에 올립니다. (Python 과 git, GitHub 로그인이 된 PC 여야 합니다.)

## 로컬 실행

```bash
pip install -r requirements.txt
python scraper/crawl.py
python -m http.server 8000 -d docs   # http://localhost:8000
```

환경변수: `SINCE`(이 날짜 이후 게시된 글만 수집·보관, 기본 `2026-06-01`), `MAX_PAGES`(탭당 최대 페이지 수 안전장치, 기본 60), `DELAY`(요청 간격 초, 기본 0.7), `REPARSE=1`(기존 글도 다시 분석), `FORCE_NEWS=1`(뉴스 6시간 제한 무시).

수집 범위는 **2026년 6월 1일 이후 게시글**입니다. 처음 한 번은 탭마다 기준일까지 끝까지 받고(`backfilled` 기록), 그다음부터는 새 글만 확인합니다. 기준일을 바꾸려면 `scraper/crawl.py` 의 `SINCE` 를 고치면 되고, 다음 실행에서 새 기준일까지 다시 받습니다.

## 참고

- 학교 서버가 SSL 중간 인증서를 보내지 않아, 수집기가 Sectigo 공식 주소에서 중간 인증서를 받아 검증 체인에 추가합니다 (검증을 끄지 않음).
- 마감일·납부기간은 본문 텍스트에서 뽑은 **추정치**입니다. 이미지나 첨부파일로만 된 공지는 추출되지 않습니다.
- 혜택 뉴스는 Google 뉴스 RSS, 날씨는 MET Norway(CC BY 4.0) 데이터입니다.
